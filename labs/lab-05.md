# Раздел 6. Использование ACL при разграничении прав доступа к файловым ресурсам

<!-- Источник: 20261028_142453.jpg; стр. 112 -->

## 6.1. Цель раздела

**Цель раздела** — получить теоретические знания и практические навыки управления доступом к объектам файловой структуры в ОС Linux с использованием механизма ACL.

## 6.2. Теоретическая информация

> Аббревиатуру **ACL** (англ. access control list) можно перевести как «список контроля доступа» [27].

Этот механизм может быть использован для построения сложных схем разграничения прав многопользовательского доступа к каталогам и файлам [38].

> **ACL** хранятся в inode-файле, который содержит правила предоставления доступа к конкретному файлу или директории.
>
> **Inode** (индексный дескриптор) — это структура данных, в которой хранится информация о файле или директории в файловой системе.

В файловых системах, используемых в ОС Linux, например в Ext4, у файла есть не только само его содержимое, но и метаданные, такие как имя, даты создания, доступа, модификации, права доступа. Все inode размещены в начале раздела диска. Чтобы просмотреть информацию из inode, используют команду **stat**.

<!-- Источник: 20261028_142455.jpg; стр. 113 -->

В качестве демонстрационного примера выполните команду:

```text
wrk1 ~ # stat /home/work
```

Вы получите метаданные файла, описывающие каталог /home/work. Также можно указать имя обычного файла:

```text
wrk1 ~ # stat /home/work/daily_data/test31.txt
```

В этом случае отобразится информация о файле. Обратите внимание на информацию о правах доступа к объекту (элемент Доступ), владельце (Uid) и группе владельца (Gid), как показано на рисунке 6.1.

Команда **chown** сменит в каталоге /home/work/ и во всех вложенных в него подкаталогах владельца на root. Рекурсивную смену владельца обеспечивает использование опции -R.

```text
wrk1 ~ # chgrp -R root /home/work/
```

Команда **chgrp** сменит в каталоге /home/work/ и во всех вложенных в него подкаталогах группу владельцев на root. Рекурсивную смену группы владельца обеспечивает использование опции -R.

3. Настройте права доступа пользователей к каталогу /home/work/, выполнив команду:

```text
wrk1 ~ # chmod -R 770 /home/work/
```

Целью выполнения данной команды было «обнуление» установленных ранее прав доступа к подкаталогам у всех остальных (кроме root) пользователей. Команда **chmod** сменит в каталоге /home/work/ и во всех вложенных в него подкаталогах права доступа. Рекурсивную смену обеспечивает использование опции -R. Специальные биты не используются. Для владельца объекта root будет установлен полный доступ (r=4, w=2, x=1, что в сумме равно 7 — первое значение).

<!-- Источник: 20261028_142526.jpg; стр. 119 -->

Для группы владельцев root также будет установлен полный доступ, так как второе значение также равно 7. У остальных пользователей (третье значение) доступ будет отнят (r=0, w=0, x=0, что в сумме равно 0).

Если вложенных подкаталогов много, то быстрее и проще «обнулить» доступ на всех сразу, а затем корректировать права для требуемых каталогов.

4. Установите только на каталог /home/work/ права на чтение данных для остальных категорий пользователей (без рекурсивного применения).

```text
wrk1 ~ # chmod 775 /home/work/
```

Остальным пользователям (третье значение) будет предоставлен доступ на прочтение информации (r=4, w=0, x=1, что в сумме равно 5). Таким образом, они смогут заходить в каталог /home/work/.

5. Проверьте права доступа к каталогам с помощью команды:

```text
wrk1 ~ # ls -la /home/work/
```

Обратите внимание, что к вложенным в /home/work каталогам доступ не имеет никто, кроме пользователя root и группы пользователей root.
