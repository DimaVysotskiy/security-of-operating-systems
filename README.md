Чтобы собрать и запустить шесть основных контейнеров на ALT Linux p11, перейдите в каталог с `compose.yaml`:

```bash
cd 'решения, основанные на Docker'
docker compose up -d --build
```

Чтобы собрать и запустить только одну работу, укажите имя сервиса: например, `docker compose up -d --build lab04`. Войти в контейнер можно командой `docker compose exec lab04 bash` или `docker exec -it "$(docker compose ps -q lab04)" bash`.

Вторые рабочие станции `lab01-wrk2` и `lab02-wrk2` запускаются отдельно по инструкциям первой и второй работ.

Пакеты скачиваются при сборке. Если штатный репозиторий ALT отвечает медленно, можно указать зеркало:

```bash
ALT_APT_MIRROR=http://mirror.yandex.ru/altlinux docker compose up -d --build
```

`docker compose restart lab04` сохраняет изменения в контейнере. Чтобы начать эту работу заново, выполните `docker compose up -d --force-recreate --no-deps lab04`: Compose заменит её контейнер новым из собранного образа.
