# Лабораторная работа № 1. Первоначальная настройка ОС

Сопоставление [исходной методички](<../../исходники (Прокушев, Я.Е. Информационная безопасность операционных систем Linux : практикум по защите информации)/исходники отцифрованные в md формат/lab-01.md>) со стендом Docker.

Номера в таблицах взяты из методички. Например, `2.5.18` — шаг 18 задания 2.5.
Буквы отмечают требования и действия без собственного номера в источнике.
Формулировки сокращены. Статусы описывают текущее решение по [Dockerfile](Dockerfile),
[compose.yaml](../compose.yaml) и [README.md](README.md).

- **Выполнено** — результат предусмотрен в стенде или в инструкции, в том числе другим способом.
- **Частично** — перенесена часть требований. Остальные перечислены в пояснении.
- **Опущено** — практический шаг отсутствует. Теория и справочные действия отмечены отдельно.
