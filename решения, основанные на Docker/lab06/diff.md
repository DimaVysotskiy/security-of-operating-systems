# Лабораторная работа № 6. Контроль целостности

Сопоставление [исходной методички](<../../исходники (Прокушев, Я.Е. Информационная безопасность операционных систем Linux : практикум по защите информации)/исходники отцифрованные в md формат/lab-06.md>) со стендом Docker.

Номер `7.3.4` означает шаг 4 задания 7.3. Буквы отмечают действия без собственного номера. Формулировки сокращены. Статусы описывают текущее решение по [Dockerfile](Dockerfile), [dirs.conf](dirs.conf), [run-osec.sh](run-osec.sh) и [README.md](README.md).

- **Выполнено** — результат предусмотрен в стенде или инструкции, в том числе другим способом.
- **Частично** — перенесена часть требований.
- **Опущено** — практический шаг отсутствует.
- **Добавлено** — дополнительная проверка в Docker-версии.
- **Пропуск в исходнике** — шаги нельзя сверить по доступной копии.
