# Лабораторная работа № 5. Списки контроля доступа (ACL)

Сопоставление [исходной методички](<../../исходники (Прокушев, Я.Е. Информационная безопасность операционных систем Linux : практикум по защите информации)/исходники отцифрованные в md формат/lab-05.md>) со стендом Docker.

Номер `6.5.3` означает шаг 3 задания 6.5. Буквы отмечают действия без собственного номера. Формулировки сокращены. Статусы описывают текущее решение по [Dockerfile](Dockerfile), [init.sh](init.sh), [Compose](../compose.yaml) и [README.md](README.md).

- **Выполнено** — результат предусмотрен в стенде или инструкции, в том числе другим способом.
- **Частично** — перенесена часть требований.
- **Опущено** — практический шаг отсутствует.
- **Добавлено** — отдельная проверка, которой нет в исходной методичке.
